## 📌 Descripción del sistema
Este proyecto simula la administración básica de un restaurante.  
Permite registrar, buscar, actualizar, eliminar y listar productos, así como registrar y listar usuarios.  
Además, muestra las categorías únicas de los productos registrados.  

El sistema está diseñado de forma modular, separando **modelos**, **servicios** y el archivo principal `main.py`.
